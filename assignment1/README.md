Electricity Bill Calculator

Files:
- index.php — the PHP-based calculator (place on a PHP-enabled server)
- style.css — responsive styles
- assignment1.rtf — assignment cover sheet with student details

Run locally (PHP 5.4+):

```powershell
php -S localhost:8000 -t .
```

Then open http://localhost:8000/index.php in your browser.

Notes:
- To push this folder to GitHub, add a remote and run `git push -u origin main` after committing.
